# 顶部汇率走势

入口在顶部运营市场右侧，随当前店铺的市场币种切换。默认展示1CNY兑换目标币种的最新日参考汇率及近30日小曲线，点击展开大图、区间变化、数据日期和来源。无店铺不显示；目标币种为CNY时显示1:1，不制造走势。

数据来自Frankfurter v2，指定ECB提供者：`https://api.frankfurter.dev/v2/rates?base=CNY&quotes=MXN&from=YYYY-MM-DD&providers=ecb`。只发送币种及日期，不发送店铺、登录凭证或业务资料，使用no-referrer。并非TikTok接口或实时成交价。参考官方说明 https://frankfurter.dev/ 。不修改定价计算器、店铺已有配置汇率或任何业务价格。

前端按币种缓存公共数据，每小时更新；超时12秒。失败保留缓存并明确提示更新失败，无缓存则显示不可用；未支持币种不编造汇率。闭市日期不补造数据点。

组件在`frontend/src/components/exchange-rate/`。沿用首页配色变量，无新依赖。顶部支持换行以避免挤压店铺操作。

实际Chrome已验证MXN最新值、迷你曲线和展开走势；构建及13项前端测试通过。多币种切换及窄窗口尚未实机验证。本轮仅本地，未发布线上。

## 当前配置

## 运行

在项目根目录执行`python3 scripts/dev-online.py start`。`status`检查本地进程，`stop`结束本次脚本创建的进程。也可以直接在frontend运行`npm run dev`。

本地页面与线上页面是不同浏览器来源。首次打开localhost需要用原线上账号正常登录一次，密码校验由线上后端执行，不需要新建或重置本地账号；线上已登录会话保留。浏览器不自动共享两个来源的localStorage。

此模式直接使用线上数据：用户在页面执行的业务写入也会发送至线上。助手验证限于读取、订单同步及界面调整，不擅自发布商品或操作买家。

Vite文件访问限制为frontend，不允许读取backend、环境文件、Git目录或密钥文件。已核对本地API代理健康返回200、后端文件访问返回403。未调整框架或安装新依赖。

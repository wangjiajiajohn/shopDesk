# 文胸链接汇总采集

来源：桌面“文胸链接汇总.xlsx”，两页共55个商品链接（文胸50、塑身衣5），包含3个TikTok商品分享链接，均按商品处理。用户后续限定先处理可打开页面。

采集保留原链接、工作表/单元格、标题、页面累计销量原文、图库和SKU颜色对应。网页中评论图、推荐商品及店铺标志不混入；图片按真实DOM结构和alt文字归类，不使用AI生成替代缺图。浏览器自动采集的“完成”声明不能代替字段检查；另用实际img元素补齐所有可见SKU图片。原图字节保留，WebP预览为Pillow确定性缩放。

工作目录：output/product-materials-import。links.json保留来源，pages/raw保留页面快照，image-scope-batch文件保留实际图片元素，manifest.json记录归档与角色，download-map.json记录地址及文件hash，verification.json记录文件尺寸/校验结果。

截至首批：31款已写入，原202款保留，素材库233款。891条采集图片记录、818个独立原图，原图约32MB，无下载失败；两款未取得独立SKU图（1732425599615275276、1732352041682440460）已在详情标明。初始2款版本也保留，因此数据库合并后的图片记录可能多于本次manifest。

导入脚本使用账号限定和商品ID查重、合并图片，不删除原记录；先校验文件和hash，事务提交，提交前保留数据库备份。3项独立临时数据库测试覆盖dry-run回滚、重复导入、账号隔离及checksum失败不写入。

新增销量展示为TikTok页面累计，不替代7天/28天榜单数值。素材库搜索“文胸链接汇总”可定位这批。类目树隐藏没有素材的分支，兼有图库和SKU用途的图片保留各自关系。构建与24项前端测试通过。未执行整库逐图人工视觉核验。

最终入库31款，表格其余24条因当前访问环境下地区限制、安全检查或页面读取失败暂跳过；最后5条已复查，仍未取得可用商品图片。report.json及skipped-links.md保留逐条来源。独立浏览器补充复核已结束；没有将受限页面返回的占位图作为新增商品入库。

复核发现某些受限页面仍返回TikTok标志或占位图，已明确排除，不将这些图片导入为商品图。重复导入再次验证新增0款；来源标题、原链接、工作表分类及销量原文均保留。

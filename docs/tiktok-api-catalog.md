# TikTok 接口资料库

本地入口：侧栏「学习与参考 → TikTok 接口资料库」。前端未发布线上。

来源是2026-11-13紫鸟中已登录Partner官方API测试工具的可见完整目录。已按虚拟列表所有383个位置采集，包含338条接口归属记录；按名称、方法和路径去重为312个接口。分组标题不计入接口数量，同一路径在多个权限包出现时分别保留。不是全部历史接口版本或每个市场全部私有能力的承诺。

数据文件：`frontend/src/data/tiktok-api-catalog.json`。不包含令牌、密钥、买家资料或真实订单标识。保留官方英文名称、路径模板、方法、分组及中文分组、工具选择状态快照、已验证版本与结果、已核实的scope映射、来源与限制。完整参数和返回结构尚未逐项归档，未知字段明确标记，不能当作可直接调用的规范。

页面支持搜索、业务/操作类型筛选、仅已验证读取、30条分页、展开记录和JSON导出。读取店铺已有授权元数据来显示是否包含已核实scope；其他权限映射保留未知。顶部选店会影响授权元数据范围，接口目录本身不按店铺隐藏。工具可选择状态、令牌权限、实测成功是不同层面的证据。

页面没有调用接口的按钮。查询/写入由名称和方法作保守初分，实际调用前仍需核对语义。生成令牌、创建导出任务等不作为无副作用查询。禁止根据查询分类推断授权执行。

评价相关：目录中发现FBT分组禁用的Product Review Removal（删除操作），没有当前墨西哥店铺的评价列表及回复状态读取；SPS差评相关分析当前官方限定美国站。未执行任何评价删除或业务写入。
